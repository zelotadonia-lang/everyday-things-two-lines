A small program for the make.fun bounty "Everyday Things, Two Lines, Longer Run". It writes one two-line text to `/output/entry.txt`: a washing machine explained to a 10-year-old as a bathtub that learned to spin, with a second line saying what the analogy maps and what it leaves out. The text won a blind tournament of 14 candidates, then won its calibration matchup 5-0 against the previous two-line winner's text.

## Run it

```sh
python3 main.py
```
